Quick Seek — On-page Translate & Search Bubble

Select any text to surface a compact action bubble showing the character count, “A⇄あ” (translate), and 🔎 (search). The translate badge opens Google Translate in a new tab so the full page is ready for screenshots.

English sample paragraph

Selecting text on this demo page will trigger the on-page action bubble. The bubble shows a codepoint-based character count, a translate badge labeled “A⇄あ”, and a search icon. The translate badge opens Google Translate directly so you can capture the external workflow. This paragraph is intentionally a bit longer so that the bubble positioning and viewport clamping are easy to capture in screenshots. It mimics typical marketing copy so the chrome extension bubble overlays feel natural within the flow of the text. Try highlighting individual sentences to verify scroll behavior across multiple lines.
