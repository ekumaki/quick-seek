# Quick Select Tools (Manifest V3)

選択テキストに対して、文字数カウント・翻訳（日本語）・Google検索を提供する軽量コンテンツスクリプト拡張機能です。UI は Shadow DOM で注入され、ページ CSS と衝突しません。プライバシー優先で、選択テキストはその場限りのメモリ内でのみ扱います。

## 機能概要

- テキスト選択時に小さなアクションバブルを表示：
  - 文字数（コードポイント基準、前後の空白トリム）。5,000 超は「5,000+」
  - 翻訳（🌐）：可能なら Chrome のオンデバイストランスレーター API を使用してページ上に翻訳バブル表示。未対応またはクロスオリジン iframe では Google 翻訳タブを開くフォールバック。
  - 検索（🔎）：Google 検索を新しいタブで開く。
- アクションバブルは選択が空/スクロール/外側クリック/ESC で自動的に閉じます。
- 翻訳バブルは画面上部中央に表示。閉じる（×/外側クリック/ESC/ナビゲーション）。
- 権限は最小限（content_scripts のみ）。バックグラウンドは不要。

## 動作要件

- Chrome で `http(s)` の通常ページ上で動作。
- `chrome://*`、Chrome ウェブストア、内蔵 PDF ビューアなどでは何もしません（Chrome によりコンテンツスクリプトは注入されません）。
- 翻訳のターゲット言語は日本語（`ja`）固定。ソース言語は自動検出。
- 検索は Google 固定。

## インストール（読み込み）方法

1. 本フォルダを任意の場所に保存します。
2. Chrome を開き、`chrome://extensions` にアクセスします。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本フォルダを選択します。

これで、通常の Web ページでテキストを選択するとアクションバブルが表示されます。

## テスト手順（クイックチェック）

1. 典型的な記事ページで 1〜20 語を選択すると、約 200ms 以内に選択の右下付近にアクションバブルが表示される。
2. 絵文字や日本語/ASCII 混在でも文字数がコードポイント長と一致し、5,000 超で「5,000+」と表示される。
3. 🌐（翻訳）クリック：
   - オンデバイス翻訳 API が使用可能かつクロスオリジン iframe でない場合：
     - ページ上部に翻訳バブルが表示され、モデル済みであれば ~800ms 程度で最初の結果が表示される（API がストリーミング対応なら逐次反映）。
     - 初回でモデルダウンロードが必要な場合は、ローディング表示後に結果が反映される。
   - 未対応またはクロスオリジン iframe の場合：
     - 新しいタブで Google 翻訳が開き、選択テキストが入力済みで表示される。
4. 🔎（検索）クリック：
   - 新しいタブで Google 検索が開き、選択テキストがクエリとして設定される。
5. `chrome://*`、ウェブストア、PDF ビューアでは何も起きず、エラーも出ない。
6. ユーザーの明示的なクリック以外では外部通信が発生しない。

## 実装メモ

- Manifest V3、content_scripts のみ。`<all_urls>` に注入（Chrome 側の制限ページでは自動的に除外）。
- UI は単一の Shadow Root に配置（`content.css` を動的ロード）。
- 選択検知は `selectionchange` と `mouseup` を使用。`Range#getBoundingClientRect()` で座標を取得し、表示位置をビューポート内にクランプ。
- 翻訳：
  - `self.translation.createTranslator(...)` が存在する場合に利用を試み、`translateStreaming` があれば逐次反映、なければ `translate` 結果を表示。
  - API が未対応・失敗時・クロスオリジン iframe では Google 翻訳タブにフォールバック。
- 検索は `window.open` で Google に新規タブ遷移（追加権限不要）。
- プライバシー：選択テキストはクリック処理中のみメモリに保持。永続保存なし。解析・解析送信なし。

## パッケージング（任意）

- 単純にフォルダを zip 圧縮し、その zip を配布可能です（Chrome ウェブストアに提出する場合はストアの手順に従ってください）。

## トラブルシューティング

- オンデバイス翻訳が動かない：現行の Chrome で当該 API が未サポート/無効な場合があります。その際は自動的に Google 翻訳タブが開くフォールバックになります。
- ページの CSS 影響：UI は Shadow DOM 内に描画しているため、ページ側の CSS 影響は最小です。
