# Quick Select Tools (Manifest V3)

選択テキストに対して、文字数カウント・翻訳（日本語）・Google検索を提供する軽量コンテンツスクリプト拡張機能です。UI は Shadow DOM で注入され、ページ CSS と衝突しません。プライバシー優先で、選択テキストはその場限りのメモリ内でのみ扱います。

## 機能概要

- テキスト選択時に小さなアクションバブル（単一の灰色カプセル）を表示：
  - 表示内容は `[ 文字数 | A⇄あ | 🔎 ]` の 3 項目。
  - 文字数はコードポイント基準（前後空白トリム）。5,000 超は「5000+字」、通常は「<数字>字」。
  - 翻訳（A⇄あ）：可能なら Chrome のオンデバイストランスレーター API を使用してページ上に翻訳バブル表示。未対応またはクロスオリジン iframe では Google 翻訳タブを開くフォールバック。
  - 検索（🔎）：Google 検索を新しいタブで開く。
- アクションバブルは選択が空/スクロール/外側クリック/ESC で自動的に閉じます。
- 翻訳バブルは画面上部中央に表示。閉じる（×/外側クリック/ESC/ナビゲーション）。
- 権限は最小限（content_scripts のみ）。バックグラウンドは不要。

## 動作要件

- Chrome で `http(s)` の通常ページ上で動作。
- `chrome://*`、Chrome ウェブストア、内蔵 PDF ビューアなどでは何もしません（Chrome によりコンテンツスクリプトは注入されません）。
- 翻訳のターゲット言語は日本語（`ja`）固定。ソース言語は自動検出。
- 検索は Google 固定。

## インストール（読み込み）方法

1. 本フォルダを任意の場所に保存します。
2. Chrome を開き、`chrome://extensions` にアクセスします。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本フォルダを選択します。

これで、通常の Web ページでテキストを選択するとアクションバブルが表示されます。

## テスト手順（クイックチェック）

1. 典型的な記事ページで 1〜20 語を選択すると、約 200ms 以内に選択の右下付近にアクションバブルが表示される。
2. 絵文字や日本語/ASCII 混在でも文字数がコードポイント長と一致し、5,000 超で「5,000+」と表示される。
3. A⇄あ（翻訳）操作：
   - オンデバイス翻訳 API が使用可能かつクロスオリジン iframe でない場合：
     - ページ上部に翻訳バブルが表示され、モデル済みであれば ~800ms 程度で最初の結果が表示される（API がストリーミング対応なら逐次反映）。
     - 初回でモデルダウンロードが必要な場合は、ローディング表示後に結果が反映される。
   - 未対応またはクロスオリジン iframe の場合：
     - 新しいタブで Google 翻訳が開き、選択テキストが入力済みで表示される。
4. 🔎（検索）クリック：
   - 新しいタブで Google 検索が開き、選択テキストがクエリとして設定される。
5. `chrome://*`、ウェブストア、PDF ビューアでは何も起きず、エラーも出ない。
6. ユーザーの明示的なクリック以外では外部通信が発生しない。

## 実装メモ

- Manifest V3、content_scripts のみ。`<all_urls>` に注入（Chrome 側の制限ページでは自動的に除外）。
- UI は単一の Shadow Root に配置（`content.css` を動的ロード）。アクションバブルは 1 つの灰色カプセルで、内部の区切り線はありません。
- 選択検知は `selectionchange` と `mouseup` を使用。`Range#getBoundingClientRect()` で座標を取得し、表示位置をビューポート内にクランプ。
- 翻訳：
  - `self.translation.createTranslator(...)` が存在する場合に利用を試み、`translateStreaming` があれば逐次反映、なければ `translate` 結果を表示。
  - API が未対応・失敗時・クロスオリジン iframe では Google 翻訳タブにフォールバック。
- 検索は `window.open` で Google に新規タブ遷移（追加権限不要）。
- プライバシー：選択テキストはクリック処理中のみメモリに保持。永続保存なし。解析・解析送信なし。

## パッケージング（任意）

- 単純にフォルダを zip 圧縮し、その zip を配布可能です（Chrome ウェブストアに提出する場合はストアの手順に従ってください）。

## トラブルシューティング

- オンデバイス翻訳が動かない：現行の Chrome で当該 API が未サポート/無効な場合があります。その際は自動的に Google 翻訳タブが開くフォールバックになります。
- ページの CSS 影響：UI は Shadow DOM 内に描画しているため、ページ側の CSS 影響は最小です。
## 翻訳の挙動と機能フラグ（重要）

- 現在のデフォルト動作では、翻訳（A⇁E）をクリックすると Google 翻訳が新しいタブで開きます。
- 将来の拡張のため、ページ上部に訳文を直接表示する「インライン翻訳バブル」のコードは温存されています。
- 機能フラグで切り替え可能です：
  - `content.js` の先頭付近にある `ENABLE_INLINE_TRANSLATION` を `true` にすると、端末内 Translator API（`self.translation`）が利用可能な環境かつ同一オリジン frame の場合のみ、ページ上部の翻訳バブルに訳文を表示します。
  - 既定値は `false` です。`false` の場合は常に Google 翻訳タブが開き、ページ上部の翻訳バブルは表示しません。
## 現状の仕様（2025-09 更新）

- アクションバブル: テキスト選択で小さなカプセルUIを表示し、以下を提供します。
  - 文字数カウント（Unicodeコードポイント基準）
  - 翻訳（A⇁E）: Google 翻訳を新しいタブで開く（既定）
  - 検索（🔎）: Google 検索を新しいタブで開く
- カプセルUIの表示方式: Shadow DOM 内で描画。ページCSSの影響を受けにくい設計。
- 最低限の見た目は JS 側の Shadow DOM 用 <style> に同梱されており、`content.css` が読めない環境でもカプセル表示が維持されます。
- 制限対象: `chrome://*`、Chrome ウェブストア、内蔵 PDF ビューア等では動作しません（Chrome により content_scripts が注入されません）。

## 翻訳機能の方針（上部バブルは既定で無効）

- 既定動作: クリック時に Google 翻訳を新規タブで開きます。
- 上部バブル（ページ内で訳文を表示する UI）は機能フラグで温存されていますが、既定では無効です。
- フラグと条件:
  - `ENABLE_INLINE_TRANSLATION`（`content.js` 冒頭）: 既定値 `false`。
  - `true` にすると、かつブラウザが on‑device Translator API（`self.translation`）に対応し、同一オリジン frame の場合のみ、ページ上部の翻訳バブルに訳文を表示します。
  - 条件を満たさない場合は常に Google 翻訳タブにフォールバックします。

## 安全性と互換性に関する実装メモ

- サイト側が `el.style` や `setAttribute('style')` をフックしている環境でも壊れないよう、インライン style 操作は行いません。
- 位置/表示など動的な変更は Shadow DOM 内の `<style>` を差し替える方式で適用します（安全・一貫）。
- UI の最低限の見た目（背景・角丸・影など）はこの動的 `<style>` に同梱し、`content.css` の読み込みに失敗してもカプセル見た目を保証します。

## トラブルシューティング（簡易）

- バブルが出ない: `chrome://*` などの制限ページや入力欄（`<input>`, `<textarea>`）内の選択では表示されません。通常の本文テキストで試してください。
- 位置ずれ: DevTools を開いた直後はレイアウトが変わるため、選択し直してください。
- 翻訳バブル（上部）が出ない: 既定で無効です。`ENABLE_INLINE_TRANSLATION=true` かつ対応API/同一オリジンの条件が必要です。
