# Quick Select Tools (Manifest V3)

選択テキストから素早く「文字数カウント・翻訳（日本語）・Google 検索」を呼び出すための軽量コンテントスクリプト拡張です。UI は Shadow DOM 内に描画され、ページ側の CSS 影響を受けにくい設計です。

## 機能

- アクションバブル（カプセルUI）を表示して次の操作を提供
  - 文字数カウント（Unicode コードポイント基準。前後空白はトリム）
  - 翻訳（A⇁E）: Google 翻訳を新しいタブで開く
  - 検索（🔎）: Google 検索を新しいタブで開く
- 見た目保証: Shadow DOM 内の動的 `<style>` に最低限の CSS を同梱。`content.css` が読み込めない場合でもカプセル見た目を維持
- プライバシー: 選択テキストはクリック処理時のみメモリ上で扱い、永続保存しません

## 使い方（テスト手順）

1. 通常の Web ページ（http/https）を開く
2. 本文テキストをいくつか選択（1〜20語程度）
3. 選択開始から ~200ms 後、選択付近にアクションバブルが表示
4. 文字数が表示され、「A⇁E」「🔎」をクリックすると、それぞれ Google 翻訳／Google 構成が新しいタブで開く

## 動作要件・制限

- 動作対象: 通常の `http(s)` ページ
- 非対象: `chrome://*`、Chrome ウェブストア、内蔵 PDF ビューア等（Chrome により content_scripts が注入されません）
- 入力欄（`<input>`, `<textarea>`）や一部の仮想化エディタでは選択を取得できない場合があります

## 実装メモ（安全性）

- ページが DOM API をフックする状況でも壊れにくいよう、インライン style 操作（`el.style` や `setAttribute('style')`）は行いません
- 位置/表示などの動的な変更は Shadow DOM 内の `<style>` を差し替える方式で適用（安全・一貫）
- 見た目の最低限の CSS はこの動的 `<style>` に同梱し、`content.css` に依存せずカプセル見た目を維持

## インストール（読み込み）

1. 本フォルダを任意の場所に保存
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」で本フォルダを選択

## トラブルシューティング（簡易）

- 何も起きない: 非対象ページや入力欄内の選択では表示されません。通常の本文テキストで試してください
- 位置ずれ: DevTools を開いた直後はレイアウトが変わることがあります。選択をやり直して確認してください
